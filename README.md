# Math Tutor Whiteboard

Сайт для онлайн-репетиторства с синхронизированной доской в реальном времени.

## Возможности

✅ **Многопользовательская доска** — все видят рисование в реальном времени  
✅ **WebSocket-синхронизация** — без задержек  
✅ **Авторизация** — вход для учеников  
✅ **Полнофункциональное рисование** — как в Zoom  
✅ **Автоматическое масштабирование** — под любой размер окна  

## Установка

```bash
npm install
```

## Запуск локально

```bash
npm run dev
```

Откройте в браузере: `http://localhost:3000`

## Учетные записи

- Учитель: `admin@example.com` / `password`
- Ученик: `student@example.com` / `password`
- Гость: можно переходить на `/board` без входа

## Как начать занятие

1. Откройте `http://localhost:3000/board`
2. Пригласите учеников открыть ту же ссылку
3. Начните писать — все видят одновременно

## Развертывание

Смотрите [DEPLOYMENT.md](./DEPLOYMENT.md) для инструкций по развёртыванию на Vercel.

## Архитектура

- **Frontend**: Next.js 14 + React + TypeScript + Tailwind CSS
- **Backend**: Next.js API + Node.js + Socket.io
- **Синхронизация**: WebSocket через Socket.io
- **Авторизация**: NextAuth.js

## Как это работает

1. Когда вы рисуете на доске, отправляется событие в Socket.io
2. Сервер получает событие и отправляет всем остальным подключённым пользователям
3. Каждый пользователь немедленно видит ваше рисование
4. Рисунки временно хранятся в памяти сервера
